# GridLess

GridLess is currently a single-page, browser-based photo editor inspired by desktop creative software.

Open `index.html` (or visit the deployed homepage) to start. The editor opens with a **Create new** dialog containing canvas presets and custom dimensions up to 4096 × 4096.

## Features

- Create transparent, white, or black canvases
- Open local images
- Brush, pencil, eraser, rectangle, text, fill, and eyedropper tools
- Basic brightness, grayscale, invert, and sepia adjustments
- Undo and redo
- Zoom controls and a simple layers panel
- Export your work as a PNG

Images are processed locally in your browser and are not uploaded. This is an early lightweight editor, not a full replacement for professional software; some toolbar icons are visual placeholders for tools not yet implemented.
